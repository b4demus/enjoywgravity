# enjoywgravity

Лаунчер для Windows, который применяет региональный патч к установленному Google Antigravity 2.35.1 и запускает приложение.

Патч предназначен для экрана с сообщением `Sorry, this account is ineligible to use Antigravity` и пояснением о недоступности приложения в текущем регионе. Он меняет обработку причины `UNSUPPORTED_LOCATION` внутри `language_server.exe`.

## Совместимость

| Компонент | Поддержка |
| --- | --- |
| ОС | Windows |
| Архитектура Antigravity | x64 |
| Версия Antigravity | 2.35.1, с проверкой точного SHA-256 |
| Среда выполнения скрипта | Встроенный Windows PowerShell 5.1 |
| Установка по умолчанию | `%LOCALAPPDATA%\Programs\Antigravity` |

Даже у файла с тем же номером версии может отличаться содержимое. Скрипт применяет патч только к файлу с известным хешем. При другом хеше он завершает работу с ошибкой.

## Быстрый запуск

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив.
2. Убедитесь, что `Start-Antigravity.cmd` и `Start-Antigravity.ps1` лежат в одной папке.
3. Перед первым применением патча полностью закройте Antigravity.
4. Если для доступа к сервисам Google вы используете VPN или прокси, включите его заранее.
5. Запустите `Start-Antigravity.cmd` двойным кликом.

При первом запуске скрипт проверит исходный файл, сохранит резервную копию, применит патч, проверит итоговый хеш и откроет Antigravity. При повторном запуске он распознает уже применённый патч и откроет приложение.

При ошибке окно `.cmd` останется открытым, чтобы можно было прочитать сообщение.

## Состав репозитория

| Файл | Назначение |
| --- | --- |
| `Start-Antigravity.cmd` | Точка запуска двойным кликом |
| `Start-Antigravity.ps1` | Проверка сборки, резервное копирование, патч и запуск |
| `.gitignore` | Исключение бинарников, резервных копий и журналов из Git |

Установленный Antigravity предоставляет `Antigravity.exe` и `resources\bin\language_server.exe`. Для работы лаунчера оба файла должны существовать в выбранной папке установки.

## Варианты запуска

Команды ниже выполняются из папки с лаунчером в командной строке Windows.

### Обычный запуск

```bat
Start-Antigravity.cmd
```

Из PowerShell запускайте файл так.

```powershell
.\Start-Antigravity.cmd
```

### Проверить совместимость

```bat
Start-Antigravity.cmd -CheckOnly
```

Команда проверяет хеш и выводит, применён ли патч. Успешная проверка выглядит так.

```text
Supported build. Patched: True
```

Значение `False` означает, что обнаружен поддерживаемый исходный файл, к которому можно применить патч.

### Применить патч

```bat
Start-Antigravity.cmd -PatchOnly
```

Этот режим завершает работу после проверки и применения патча. Приложение можно открыть позднее.

### Указать другую папку установки

```bat
Start-Antigravity.cmd -InstallDirectory "D:\Apps\Antigravity"
```

Путь должен указывать на папку, содержащую `Antigravity.exe`. Параметры можно сочетать.

```bat
Start-Antigravity.cmd -InstallDirectory "D:\Apps\Antigravity" -CheckOnly
```

При сочетании `-CheckOnly` и `-PatchOnly` выполняется только проверка.

## Что именно меняется

В проверенной сборке функция `authclient.ValidateAndOnboardAccount` обрабатывает список `IneligibleTier`, полученный при настройке аккаунта. Во встроенном protobuf-описании значение `UNSUPPORTED_LOCATION` равно `3`.

Патч добавляет проверку `reason_code == 3` и переход к следующему элементу списка причин отказа. Остальные элементы продолжают проходить существующую обработку.

| Значение | Проверенная сборка |
| --- | --- |
| Функция | `authclient.ValidateAndOnboardAccount` |
| Смещение в файле | `0x306502f` |
| RVA | `0x3065a2f` |
| Размер переписанного участка | 81 байт |
| Число отличающихся байтов | 68 |
| SHA-256 исходного файла | `73CE9A2405B455A93D1F13DB2AE555DA50406110217A349B6DD85C377FBDB9D1` |
| SHA-256 файла после патча | `E958319DE43E1425DBFA00B0503B30809A6B8ED854C2AE1C8849B81904F0DDE1` |

Патч сохраняется на диске после закрытия лаунчера. Последующие обычные запуски Antigravity также используют изменённый `language_server.exe`.

Сетевое соединение с Google продолжает обслуживать установленное приложение. Доступность моделей зависит от ответов сервиса, аккаунта и сетевого маршрута. Проверенный запуск выполнялся с активным Throne в режиме TUN.

## Резервная копия и откат

При первом применении скрипт создаёт рядом с сервером файл.

```text
resources\bin\language_server.exe.original-2.35.1
```

Перед записью патча скрипт проверяет SHA-256 резервной копии. Существующая копия с другим хешем вызывает ошибку.

Для отката полностью закройте Antigravity и выполните в PowerShell следующие команды. При другой папке установки измените первую строку.

```powershell
$installation = Join-Path $env:LOCALAPPDATA 'Programs\Antigravity'
$server = Join-Path $installation 'resources\bin\language_server.exe'
$backup = "$server.original-2.35.1"
$expected = '73CE9A2405B455A93D1F13DB2AE555DA50406110217A349B6DD85C377FBDB9D1'

if ((Get-FileHash -LiteralPath $backup -Algorithm SHA256).Hash -ne $expected) {
    throw 'Unexpected backup hash'
}
Copy-Item -LiteralPath $backup -Destination $server -Force
if ((Get-FileHash -LiteralPath $server -Algorithm SHA256).Hash -ne $expected) {
    throw 'Restore verification failed'
}
```

Если установленный файл ранее был пропатчен вручную, лаунчер распознаёт его по хешу. В таком случае оригинал для отката нужно взять из резервной копии, созданной при ручном патче.

После отката запускайте Antigravity обычным ярлыком. Запуск через этот лаунчер применит патч повторно.

## Обновления Antigravity

Обновление может заменить `language_server.exe`. Для новой сборки потребуется заново проверить машинный код и подготовить соответствующий патч. Самостоятельная замена ожидаемых хешей в скрипте не подтверждает совместимость смещений и инструкций.

## Сообщения об ошибках

| Сообщение | Действие |
| --- | --- |
| `Antigravity not found` | Укажите фактическую папку через `-InstallDirectory` |
| `Unsupported language_server build` | Сравните версию и SHA-256 с таблицей совместимости |
| `Close Antigravity before applying the patch` | Полностью закройте приложение и повторите запуск |
| `Existing backup has an unexpected hash` | Проверьте происхождение резервной копии и её SHA-256 |
| `Another patch launcher is busy` | Дождитесь завершения другого экземпляра лаунчера |
| `Patched file verification failed` | Скрипт пытается восстановить исходные байты и сообщает об ошибке |
| `Restore failed` | Закройте приложение и восстановите файл из проверенной резервной копии |

Права на запись нужны в папке установленного Antigravity. Обычно пользовательская установка в `%LOCALAPPDATA%` доступна текущему пользователю. Если запись запрещена, проверьте права на фактическую папку установки.

Для получения SHA-256 можно использовать PowerShell.

```powershell
Get-FileHash -LiteralPath "$env:LOCALAPPDATA\Programs\Antigravity\resources\bin\language_server.exe" -Algorithm SHA256
```

При обращении с проблемой достаточно указать версию Antigravity, SHA-256 и точный текст ошибки. Журналы приложения могут содержать данные аккаунта и содержимое проектов.

## Выполнение PowerShell

`.cmd` запускает встроенный `powershell.exe` с `-NoProfile` и `-ExecutionPolicy Bypass` для текущего дочернего процесса. Он также задаёт стандартный путь модулей Windows PowerShell внутри своего окружения. Это позволяет запускать лаунчер из оболочек с другим набором модулей.

Для защиты от одновременного запуска используется именованный mutex. Во время изменения файла скрипт удерживает эксклюзивный файловый дескриптор. При обнаруженной ошибке записи или несовпадении итогового хеша он пытается вернуть сохранённые исходные байты. Резервная копия также позволяет восстановить файл после аварийного завершения процесса.

## Проверка результата

На проверенной установке после патча журнал показал `get_auth_status valid=true`. В интерфейсе открылся рабочий чат, а модель Gemini 4 Neon High ответила на приветствие. В журнале появились идентификаторы ответов `streamGenerateContent`.

Для лаунчера выполнены проверки применения к копии исходного файла, хеша резервной копии, итогового хеша, повторного применения и отклонения неизвестного файла. Также проверен запуск через `.cmd` на уже пропатченной установке.

Эти результаты относятся к указанной сборке и проверенной конфигурации. Для своей установки проверьте вход и отправьте короткое сообщение выбранной модели.
